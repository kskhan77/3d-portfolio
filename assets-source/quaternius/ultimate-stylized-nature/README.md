# Quaternius Nature Source Assets

Place the downloaded `Ultimate Stylized Nature Pack` source files here.

Recommended workflow:

1. Download the pack from Quaternius.
2. Keep the original archive and source files in this folder.
3. Export only the selected assets we want to use to `.glb`.
4. Put optimized runtime files in:

```text
public/models/nature/
```

Suggested runtime filenames:

- `tree-round.glb`
- `tree-pine.glb`
- `bush-round.glb`
- `rock-large.glb`
- `rock-small.glb`
- `flower-patch.glb`
- `grass-clump.glb`
- `log-small.glb`

The current app is scaffolded to work even before these files exist.
